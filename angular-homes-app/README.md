# Homes App (Angular)

A housing listings app built by following Angular's official ["Build your first Angular app"](https://angular.dev/tutorials/first-app) tutorial. It covers standalone components, `@Input`, services and dependency injection, routing with route parameters, a reactive application form, and loading data over HTTP from a mock JSON server.

```bash
npm install
npx json-server --watch db.json   # mock API on http://localhost:3000
npm start                         # app on http://localhost:4200
```

Listing photos are from Unsplash, via the Angular tutorial.
